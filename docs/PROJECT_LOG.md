## Хронология

### 2026-11-21 — Онлайн-мультиплеер (Claude Code, автономно)

- game-core на 2–4 игрока (места p1..p4, карты «Тройная система» и «Четыре системы», выбывание, `getRanking`).
- `packages/protocol` — контракт клиент ↔ сервер; `apps/server` — Fastify + Socket.IO + Postgres, миграции, гостевые токены (sha256), комнаты, авторитетный цикл матча с таймерами, маскирование чужих ответов/ставок, запись событий (матч воспроизводится по сиду), 11 интеграционных тестов. В CI добавлен Postgres-сервис.
- Клиент: `/online` (ник, создать комнату, войти по коду), `/room/CODE` (ссылка-приглашение, комната ожидания, матч, реванш), `MatchView` общий для бота и онлайна, индикатор связи и переподключение.
- Живая проверка в двух вкладках (localhost и 127.0.0.1): создание и вход по ссылке, готовность, раздел, бои, ва-банк, итог, реванш, перезагрузка посреди вопроса, обрыв сокета. Правки по итогам: устаревший токен по HTTP сбрасывает сессию; «сопернику N планет»; над итогом «Соперник: …»; кнопка онлайна скрыта в релизе без адреса сервера.
- Банк вопросов расширен до 4939 (ЧГК-короткие, сайты викторин в своей редакции, Wikidata).
- Осталось: выкладка сервера (по команде пользователя), UI на 3–4 игрока вживую.

### 2026-11-20 — Большой редизайн (Claude Code, автономно)

**Запрос пользователя:** «примитивно, хочу продуманный дизайн, не нейрослоп, больше вопросов, интереснее». Ответы на уточнения: стиль — на выбор агента; ядро механики оставить и углубить; вопросы — эрудиция на любые темы (космос — только оформление); коммитить и пушить прямо в master разрешено.

**Ресерч:** `docs/research/ux-and-mechanics.md` (тайминги ответа и раскрытия, сектора, «Ва-банк», визуальное направление «Космоплакат»).

**Сделано:**
- `game-core`: сектора (`state.sectors`, атака спрашивает тему цели), `PlanetKind` + `KIND_VALUE`, бустеры (`BOOST`, `usableBoosters`), серии → бустер, аванпосты → бустер, `Opponent` (5 командиров в `bot/opponents.ts`), финал `wager` (`WAGER`, `maxWager`, `botWager` по логике Final Jeopardy), `tally`/`events` для итогов. `MatchState.version = 4`.
- UI переписан: `Slab` (жёсткая тень), `Button`, `PlanetArt` (планеты из плоских форм + полутон), `CategoryGlyph` (14 линейных иконок), `Avatar` (портреты командиров), `Poster`, `StarMap`, `PlanetCard`, `QuestionStage`, `NumberLine`, `WagerPanel`, `ResultPanel`, `Hud`; экраны `/`, `/briefing`, `/match`, `/rules`, `/stats`.
- Стор: пауза на чтение (`readingMs`), бот тратит бустеры и ставит ставки, прогресс кампании и статистика по темам (`storage/progress.ts`), настройки звука/вибрации.
- Банк вопросов пересобран: **774** вопроса по 14 категориям (546 MCQ / 228 числовых, сложность 37/44/20 %), у каждого `fact`; валидатор требует `fact` и категорию из фиксированного списка, числовые ответы — целые ≥ 0. id вида `hist-001`. Сомнительные факты помечены «по легенде»/«округлённо» или удалены.
- В dev-сборке стор доступен как `globalThis.__sc` — удобно для проверки в браузере.

**Проверено:** `npm run check`; в браузере на 375×812: главная, брифинг, правила, вопрос MCQ/числовой, бустеры, карта, атака, тай-брейк, ставка, итоги; полный матч автоигроком через реальный стор (раздел → 8 ходов → ва-банк → итог).

### 2026-11-19 — Полное ревью и переделка (Opus)

**Ревью — что было плохо:**

- *Запуск:* Expo SDK 52 — текущий Expo Go (SDK 58) его не открывает, на телефоне игра не запускалась; костыль `query-string@7`; невалидный `exports` в `game-core/package.json`; `node` не в PATH.
- *Ядро:* софтлоки (игрок без доступных планет/целей навсегда вешал матч); после expansion при недобранной карте фаза ставилась `battle`, но шёл ещё вопрос expansion; бонус за захват тут же затирался пересчётом; числовые вопросы при неточных ответах решались по скорости, а не по близости; мутация предыдущего состояния (`owners`); у бота столица давала 200 очков против 1000 у игрока; точность бота росла со сложностью вопроса; в сообщениях сырые id («Выбор: human»).
- *Контент:* 46 дублей (вопросы 101–150 — копии), арифметика «3+3+3?», ответ в тексте вопроса, фактические ошибки; правильный вариант в 70% MCQ на позиции B.
- *UI:* отладочный экран: маленькая карта, планеты выбирались кнопками-списком, английские «expansion/battle», нет разбора ответа, вопрос уезжал за экран, нет выхода в меню.

**Сделано:**

- SDK 52 → 58, TS 6, чистая переустановка; root-скрипты `web/start/android/ios/check`, `.nvmrc`.
- `game-core` переписан (`types.ts`, `engine/match.ts`, `engine/rules.ts`, `bot/bot.ts`, `questions.ts`, `rng.ts`, карта `map/sol-system.ts` — 13 тел, симметричная).
- Тесты: правила раздела/битвы/тай-брейка/столицы + 300 симулированных матчей (без зависаний, без мутаций, deep-freeze) + «сложный бот побеждает лёгкого».
- Баланс (400 симуляций): ~16 вопросов за матч; normal vs normal ≈ 54/44/2; hard vs normal ≈ 91%.
- Новый `ru.json` (238), валидатор: дубли текста, 4 варианта, уникальность вариантов.
- Новый UI: `Screen`, `SpaceBackground`, `StarMap`, `Hud`, `QuestionPanel`, `NumericPad` (+ клавиатура на вебе), `RevealPanel`, `ResultPanel`, `Sheet`, `Logo`; экраны `/`, `/rules`, `/match`. Статистика побед, выбор сложности, продолжение матча после перезапуска.
- Проверено в браузере: меню → правила → полный матч автоматическим игроком.

**Тесты:** `npm run check` — OK.
