# Space Conquistador

Квиз-стратегия про захват Солнечной системы (мотив Triviador / ConQUIZtador). React Native + Expo, вопросы на русском, матч против бота. Платформы: Android (основная), iOS, веб для быстрой проверки.

## Запуск

Нужен Node 22 (`.nvmrc`). Если `node` не находится — Homebrew-версия лежит вне PATH:

```bash
export PATH="/opt/homebrew/opt/node@22/bin:$PATH"
```

```bash
npm install          # один раз, из корня
npm run web          # игра в браузере: http://localhost:8081
npm start            # dev-сервер + QR-код для телефона
npm run check        # вопросы + типы + тесты
```

**На телефоне (Android/iOS):** поставьте **Expo Go** из Google Play / App Store, запустите `npm start` и отсканируйте QR-код (телефон и компьютер в одной Wi-Fi сети). Проект на Expo SDK 58 — это версия, которую поддерживает текущий Expo Go.

## Как играть

1. **Раздел системы.** Оба игрока отвечают на один вопрос. Самый быстрый верный ответ — 2 планеты, второй верный — 1. В числовых вопросах побеждает тот, кто ближе. Брать можно свободные планеты рядом со своими.
2. **Битва.** Ходы по очереди: атакуете соседнюю вражескую планету, оба отвечают. Оба верно — решающий числовой вопрос. Отбитая атака даёт защитнику +100.
3. **Столица** имеет 3 щита; если сбить все — вся система переходит атакующему.
4. Очки: планета 200, отвоёванная 300, столица 1000. Победа — по очкам после 8 ходов битвы или падением столицы.

## Структура

- `packages/game-core` — вся логика матча (чистый TypeScript, тесты на vitest)
- `apps/mobile` — Expo-приложение (экраны, карта, анимации)
- `content/questions/ru.json` — банк вопросов (проверка: `npm run validate:questions`)
