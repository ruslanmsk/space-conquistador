# План разработки Space Conquistador

Подробный план. Статус выполнения дублируется чеклистами в [`PROJECT_LOG.md`](PROJECT_LOG.md).

---

## Видение

Онлайн-квиз про захват планет: игрок и соперники (сначала **бот**) отвечают на вопросы, чтобы занимать секторы звёздной системы, дуэлиться за чужие планеты и набирать очки. Визуал — схематичная карта-созвездие, не географическая карта Земли.

### Референс-механики (Triviador / ConQUIZtador)

1. **Старт** — выбор домашней базы (планета-«столица»).
2. **Expansion** — несколько раундов: общий вопрос → по скорости/точности право захватить N соседних свободных секторов.
3. **Battle** — атака соседней чужой планеты: дуэль по вопросу (MCQ или числовой «ближе к ответу»).
4. **Столица** (позже) — 3 «башни» / уровня защиты; проигрыш при падении столицы.
5. **Победа** — больше очков или полный контроль системы.

- [x] Все живые игроки отвечают на один вопрос

### 1.4 Battle

- [x] Выбор цели — соседняя вражеская планета

- [x] Выбор захвата: случайный допустимый; атака — слабый сосед / пограничная

## Риски

| Риск | Митигация |
|------|-----------|
| Скучный бот | Увеличить «агрессию» и точность по сложности матча |
| Мало вопросов | Пакетная генерация + ручная вычитка позже |
| RN perf на карте | SVG, не 3D |
| Переписывание при онлайне | Вся логика в `game-core` с чистыми функциями |

## Определение готовности MVP

Игрок с телефона проходит полный матч 1v1 с ботом на одной карте, ≥50 вопросов в пуле, без крашей, RU интерфейс.
